## 🚀 Featured Projects

### ☁️ [CloudForge](https://github.com/shrikant-nidasheshi/End-to-End-Cloud-Native-DevOps-Platform): Automated EKS Delivery Platform
21 Dockerized microservices on **Amazon EKS**, with infrastructure provisioned by **Terraform** and delivered through a **GitOps** pipeline (GitHub Actions, Helm, Argo CD). Includes RBAC, Service Accounts, and AWS ALB Ingress.
`AWS EKS` `Terraform` `Helm` `Argo CD` `GitHub Actions` `Docker`

### 💰 [CostPilot](https://github.com/shrikant-nidasheshi/AWS-Resource-Utilization-and-Cost-Optimization-Dashboard): Serverless FinOps Platform
Serverless platform that detects underutilized EC2 instances and EBS volumes, with a React dashboard for insights and automated cleanup. Uses AWS Compute Optimizer for right-sizing recommendations.
`Lambda` `API Gateway` `DynamoDB` `EventBridge` `React.js` `Python`

### 🛡️ DevSecOps Blog Platform
3-tier blog application (React, Node.js, PostgreSQL) on EKS with security scanning built into the pipeline (Trivy, Checkov, Hadolint, ESLint, npm Audit) and Kubernetes hardening with NetworkPolicies and non-root containers.
`Kubernetes` `Terraform` `GitHub Actions` `Trivy` `Checkov`
